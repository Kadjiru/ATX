ATX 0.1.0 — Windows 10/11 x64, Aion 2 Global (EU/NA)

РУССКИЙ
1. Установите Npcap с https://npcap.com/#download с настройками по умолчанию.
2. Запустите ATX-Setup-v0.1.0.exe. Для портативной версии распакуйте весь архив и откройте ATX.exe.
3. Запустите ATX до входа в Aion 2. Войдите персонажем и вступите в группу.
   Если ATX запустился позже игры, телепортируйтесь или смените локацию.
4. Если ATX не видит игру, проверьте Настройки → Захват. Попробуйте автоматический
   выбор адаптера или нужный адаптер при VPN. Если Npcap установлен с доступом только
   администраторам, разрешите доступ к драйверу либо переустановите его с настройками по умолчанию.
5. Используйте оконный режим без рамки для HUD. Ctrl+Shift+D включает боевой HUD,
   Ctrl+Alt+T — отсчёт активностей. Для карты нужен интернет и Edge WebView2 Runtime.
6. Обновления проверяются в Настройки → Обновления. Портативную версию обновляйте
   распаковкой нового архива. Данные хранятся в %AppData%\ATX.

ENGLISH
1. Install Npcap from https://npcap.com/#download with default options.
2. Run ATX-Setup-v0.1.0.exe. For the portable version, extract the full ZIP and run ATX.exe.
3. Open ATX before logging into Aion 2. Enter a zone and join your party.
   If you opened ATX after the game, teleport or change zones.
4. If ATX cannot detect the game, check Settings → Capture. Try automatic adapter
   selection or the appropriate adapter when using a VPN. If Npcap was installed in
   administrator-only mode, allow driver access or reinstall it with default settings.
5. Use borderless windowed mode for the HUD. Ctrl+Shift+D toggles the combat HUD.
   Ctrl+Alt+T toggles activity countdowns. The map needs internet and Edge WebView2 Runtime.
6. Check for updates in Settings → Updates. For portable copies, extract the new ZIP.
   Data is stored in %AppData%\ATX.

ATX includes its own .NET runtime. Npcap is installed separately.
