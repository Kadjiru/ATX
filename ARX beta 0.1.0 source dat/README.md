# ARX 0.1.0 beta

Настольный помощник для легиона **ARX** в Aion 2 Global. Приложение использует русскоязычный интерфейс, локальный атлас, отдельные HUD и собственную иллюстрацию.

## Установка

1. Скачайте **ARX-Setup-0.1.0-beta.exe** из бета-релиза. Запустите установщик и ознакомьтесь с лицензией GPL‑3.0.
2. Выберите папку, установите ARX и откройте его из меню «Пуск». Ярлык рабочего стола добавляется по желанию.
3. Портативный вариант: распакуйте весь ZIP и откройте **ARX.Beta.exe**. Папка **Data** должна остаться рядом.

Среда .NET входит в сборку x64. Установщик проверяет версию Windows и наличие UCRT, DirectWrite, Direct3D 11 и DXGI. Для стабильной работы используйте поддерживаемую Microsoft Windows. Установщик без цифровой подписи.

## В игре и между забегами

- **Разбор и история.** Внесите результаты из окна Combat Analysis или импортируйте собственный CSV. Для ручных итогов используйте строки `Имя;Урон;Лечение`. Введите длительность боя в секундах. Для CSV сохраните шаблон из приложения. Его поля: `seconds,player,skill,damage,healing,critical`. Время относительное, с десятичной точкой. Поле `critical` принимает `true/false` или `1/0`. Длительность CSV выводится из времени последней строки. Детали навыков и график требуют событий боя. Автоматического захвата и определения группы в этой сборке нет.
- **Отдельные HUD.** Кнопки «Урон», «События» и «Задачи» открывают независимые окна поверх рабочего стола и игры в оконном режиме без рамки. Перетащите окно за заголовок и нажмите ◐ для прозрачности. Кнопка ARX возвращает главное окно.
- **Атлас.** Выберите зону, создайте метку и отметьте находку. Колесо масштабирует, перетаскивание двигает карту. Контуры и масштаб авторские и условные. В бете семь зон, пользовательские и общие метки. Геометрия клиента, полный набор игровых точек и привязка к позиции персонажа отсутствуют.
- **События.** Пресеты разлома и фестиваля сверены с расписаниями сообщества. Сверьте время с вашим сервером. Редактор принимает UTC и период повтора. В интерфейсе время следующего события показывается в часовом поясе Windows.
- **Сессия.** Задачи и ручной журнал расходов и доходов кина. Новая сессия открывает новый список задач. Движение кина сохраняется в общей сводке профиля.
- **Мастерская и гайды.** Поиск по 528 рецептам и 703 предметам. Калькулятор считает количество изготовлений, остатки и стоимость закупки по введённым ценам. Рецепты помечены датой Global LST, подборки предметов и рейдовая памятка опираются на данные ноябрьского обновления. После игрового патча сверяйте рецепт в клиенте.

## Синхронизация

При запуске ARX сверяет ревизию базы в ветке беты на GitHub. Обновление проходит проверку формата и SHA‑256. При недоступности сети открывается последняя рабочая копия. Это справочник ARX с указанными датами источников. Он обновляется по мере публикации новых ревизий.

Для общего набора участники выбирают одну и ту же общую папку в **Настройки → Синхронизация легиона**. Подойдёт уже настроенная сетевая папка либо каталог службы синхронизации. Редактор с правом записи нажимает **Опубликовать мои метки и таймеры**. ARX записывает `arx-legion.json` и читает изменения каждые 15 секунд. Выдача доступа и перенос файлов между компьютерами выполняются выбранной службой. Рекомендуется один редактор с правом записи. Его публикация заменяет предыдущий общий набор.

Боевые отчёты, задачи, кина, имя персонажа и отметки о находках остаются в локальном профиле `%AppData%\ARX Legion Beta`. Для переноса личного профиля закройте ARX и скопируйте папку. При удалении приложения профиль остаётся доступен.

## Изменение исходников

Откройте **ARX.Beta.csproj** в IDE с .NET 10 SDK либо выполните в этой папке:

~~~powershell
dotnet build .\ARX.Beta.csproj -c Release
.\build-beta.ps1
~~~

Установщик собирается при наличии Inno Setup 7 и доступного в PATH `ISCC.exe`. Чтобы обновить справочник, измените **Data/Crafting.json** или **Data/Reference.json**, выполните `.\Update-CatalogManifest.ps1 -Revision 2` с номером выше опубликованного и сохраните все три JSON-файла одним коммитом в ветке `beta/0.1.0`.
