ARX 0.1.0 beta — легион ARX / Aion 2 Global

УСТАНОВКА
1. Запустите ARX-Setup-0.1.0-beta.exe и ознакомьтесь с GPL-3.0.
2. Установщик проверит Windows x64 и системные библиотеки. .NET уже в комплекте.
3. Выберите каталог и при необходимости ярлык на рабочем столе.
4. Откройте ARX из меню «Пуск». Портативная версия запускается через ARX.Beta.exe
   после распаковки всего ZIP. Оставьте папку Data рядом с приложением.

БЫСТРЫЙ СТАРТ
• Кнопки «Урон», «События» и «Задачи» открывают отдельные HUD.
  Для размещения поверх Aion 2 используйте оконный режим без рамки.
• В «Разборе и истории» внесите итоги или импортируйте события из CSV.
• В «Атласе» выберите зону, создайте метку и отмечайте находки.
• В «Настройках» выберите общую папку легиона. Редактор публикует в ней метки
  и таймеры. Участники с доступом получат общий набор автоматически.
• При запуске база сверяется с репозиторием ARX. Без сети работает локальная копия.

Личный профиль хранится в %AppData%\ARX Legion Beta. Удаление ARX оставляет профиль.
