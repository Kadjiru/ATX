ARX 1.0.9 stable / Aion 2 Global

1. Запустите ARX-Setup-1.0.9.exe и ознакомьтесь с GPL-3.0.
2. Установщик проверит Windows x64 и её системные библиотеки. .NET уже в комплекте.
   Если Npcap отсутствует, выберите «Скачать и установить Npcap».
   ARX проверит загруженный файл и запустит официальный мастер драйвера.
   Шаг можно пропустить. Windows может запросить права администратора.
3. Запустите ARX. Считывание включится автоматически. Проверьте статус в верхней строке.
4. Нажмите «Обновление» рядом со статусом клиента. После подтверждения
   ARX покажет ход установки и откроется автоматически.
   При первом запуске обновлённой версии появится окно «Что нового».
   Если игра уже запущена, смените локацию. Проверка адаптера есть в «Настройках».
5. Для HUD используйте оконный режим без рамки. Alt+F8 управляет HUD урона.
   Ctrl+Alt+1/2/3 меняют плотность, Ctrl+Alt+PgUp/PgDn — непрозрачность.
   Ctrl+Alt+L закрепляет HUD с пропуском щелчков. Alt+R завершает сегмент.
   Ctrl+Alt+F10 открывает миникарту. Ctrl+Alt+F11 закрепляет её.
   Удерживайте Alt для управления закреплённым HUD или миникартой.
6. Для портативной версии распакуйте ZIP целиком и откройте ARX.Beta.exe.

Встроенный атлас поддерживает пользовательские метки и локальные снимки зон.
В «Забегах» можно сохранять несколько боёв и сравнивать результаты.
В «Билдах и гайдах» сохраните сборку персонажа или выберите бой.
В «Питомцах» доступны карточки со значками семейств, поиск и инструкция по прокачке.
Справочник и таймеры используют локальную копию данных, когда сеть недоступна.

Язык интерфейса / Interface language
Настройки → Язык / Language → English. Сохраните выбор и перезапустите ARX.
Open Settings → Язык / Language, choose English, save and restart ARX.

Настройки → Оформление. Выберите отдельные темы для приложения и HUD.
Open Settings → Appearance to choose separate themes for the app and HUDs.

Профиль предыдущей беты сохранён в %AppData%\ARX Legion Beta.
