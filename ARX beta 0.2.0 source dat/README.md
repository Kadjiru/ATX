# ARX 0.2.1 beta

Общедоступное приложение для Aion 2 Global (EU/NA). Для использования ARX не требуется аккаунт или членство в группе.

## Установка

1. Запустите **ARX-Setup-0.2.1-beta.exe**, ознакомьтесь с GPL‑3.0 и завершите установку. Установщик включает .NET и проверяет системные компоненты Windows x64.
2. Для живой статистики установите [Npcap](https://npcap.com/#download) с настройками по умолчанию. Установщик ARX подскажет, если драйвер отсутствует. Портативная версия работает из распакованного ZIP с папками **Data** и **GameData**.
3. Откройте **Монитор → Начать захват**. Лучше сделать это до входа персонажем. Если ARX включён посреди игры, перейдите в другую локацию. При проблемах проверьте адаптер в **Настройках**.
4. Используйте оконный режим без рамки для HUD. Установщик без цифровой подписи.

## Бой, отчёты и забеги

ARX пассивно распознаёт поток Aion 2 через Npcap. После обнаружения состава отчёт фильтруется по участникам. При неизвестном составе видны наблюдаемые игроки. На массовых боях сервер может присылать часть урона. Имена и боевая мощь показываются по данным сервера. Трафик игры, сырые пакеты и отчёты не отправляются из приложения. NCSOFT не предоставляла ARX отдельное разрешение на захват.

- **Монитор** показывает DPS, урон, полученное лечение, пик за 5 секунд, график и доли участников. В боевых отчётах доступны навыки, HPS, крит, атаки со спины, максимальный и полученный урон. Поглощение щитами и вклад баффов не рассчитываются.
- **Забеги** собирают завершённые боевые сегменты после ручного старта. Задайте название и билд, затем завершите или прервите забег с сохранением. Можно сравнить средний DPS двух забегов и экспортировать JSON. Завершение всего забега выполняется вручную.
- **Отчёты** сохраняют бои, позволяют снять снимок текущего сегмента и экспортировать JSON. Для ручного ввода доступны строки «Имя;Урон;Лечение». Для импорта точных событий в приложении есть шаблон CSV.
- **HUD** открываются независимо. У боевого HUD три режима: минимальный с итогами, средний со списком участников и подробный с долями, критами, бурстом, боевой мощью и доступным HP цели. Непрозрачность регулируется от 35 до 100%. Закрепление пропускает щелчки к игре.

| Клавиша | Действие |
| --- | --- |
| Alt+F8 | Показать или скрыть боевой HUD |
| Ctrl+Alt+1 / 2 / 3 | Открыть минимальный, средний или подробный режим |
| Ctrl+Alt+PgUp / PgDn | Изменить непрозрачность на 5 п. п. |
| Ctrl+Alt+L | Закрепить или разблокировать HUD |
| Alt+R | Завершить текущий сегмент |

В клиенте откройте вкладку **Горячие клавиши**. Она показывает действия и состояние регистрации каждого сочетания. Если сочетание занято, пользуйтесь настройками HUD в ARX. Закрепление доступно, когда Ctrl+Alt+L зарегистрирована и HUD можно разблокировать с клавиатуры.

## Карта, таймеры и прогресс

Атлас работает внутри приложения. На авторской схеме семи зон доступны масштабирование, перетаскивание, категории, фильтр ненайденных меток и маршруты в порядке добавления. Двойной щелчок по метке в списке центрирует её. Для точного ориентира по своей карте загрузите локальный PNG/JPEG через **Снимок карты…**. Координаты такого слоя привязаны к выбранному изображению, метки сохраняются отдельно. Автоматической геолокации персонажа и полного каталога игровых точек нет.

Полевые боссы появляются в **Событиях** после открытия игрового списка полевых монстров при включённом захвате. Для полученного времени можно включить звуковое напоминание. Остальные таймеры используют редактируемое расписание. Во вкладке **Прогресс** доступны личные ежедневные, еженедельные и постоянные счётчики с ручным сбросом периодов. **Сессия** содержит задачи и ручной журнал кина.

## Данные и обмен

При запуске ARX проверяет ревизию справочника на GitHub и использует локальную копию без сети. Рецепты и цены в калькуляторе не являются актуальной выгрузкой аукциона. Дата среза показана в мастерской.

Общая папка в **Настройках** необязательна. Участники с доступом к одному каталогу могут обмениваться набором меток схемы и таймеров. Частные слои карты, отчёты, задачи, кина и личные отметки остаются в профиле. Для совместимости с предыдущей бетой ARX продолжает использовать папку %AppData%\ARX Legion Beta.

## Исходный код

Откройте **ARX.Beta.csproj** в IDE с .NET 10 SDK. Для сборки нужны соседние каталоги **src/AionMeter.Core** и **data** из архива исходников. Для установщика нужен Inno Setup 7, а ISCC.exe должен быть в PATH.

~~~powershell
dotnet build .\ARX.Beta.csproj -c Release
.\build-beta.ps1
~~~

Обновление справочника: измените Data/Crafting.json или Data/Reference.json, запустите .\Update-CatalogManifest.ps1 -Revision 2 с номером выше опубликованного и сохраните три JSON-файла одним коммитом.
