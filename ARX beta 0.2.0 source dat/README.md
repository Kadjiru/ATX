# ARX 0.2.4 beta

Общедоступное приложение для Aion 2 Global (EU/NA). Для использования ARX не требуется аккаунт или членство в группе.

## Установка

1. Запустите **ARX-Setup-0.2.4-beta.exe**, ознакомьтесь с GPL‑3.0 и завершите установку. Установщик включает .NET и проверяет системные компоненты Windows x64.
2. Для живой статистики установите [Npcap](https://npcap.com/#download) с настройками по умолчанию. Установщик ARX подскажет, если драйвер отсутствует. Портативная версия работает из распакованного ZIP с папками **Data** и **GameData**.
3. Запустите ARX. Считывание включится автоматически, а в верхней строке появится статус подключения. Лучше открыть ARX до входа персонажем. Если ARX включён посреди игры, перейдите в другую локацию. При проблемах проверьте адаптер в **Настройках**.
4. Используйте оконный режим без рамки для HUD. Установщик без цифровой подписи.

## Бой, отчёты и забеги

ARX пассивно распознаёт поток Aion 2 через Npcap. После получения состава DPS отображается отдельно по участникам, а прочерк означает, что боевых данных по игроку пока нет. Состав обновляется при получении нового списка или сообщения о выходе из группы. При неизвестном составе видны наблюдаемые игроки. На массовых боях сервер может присылать часть урона. Имена и боевая мощь показываются по данным сервера. Трафик игры, сырые пакеты и отчёты не отправляются из приложения. NCSOFT не предоставляла ARX отдельное разрешение на захват.

- **Монитор** показывает ваш DPS отдельно от общего, индивидуальные строки участников и график. Метка **ВЫ** ставится по идентификатору собственного персонажа из пакета игры. Если ARX запущен после входа и ещё не получил этот пакет, смените локацию или укажите точное имя в разделе **Настройки → Подключение Aion 2**. Резервный поиск требует единственного совпадения. В боевых отчётах доступны навыки, HPS, крит, атаки со спины, максимальный и полученный урон. Поглощение щитами и вклад баффов не рассчитываются.
- **Забеги** собирают завершённые боевые сегменты после ручного старта. Задайте название и билд, затем завершите или прервите забег с сохранением. Можно сравнить средний DPS двух забегов и экспортировать JSON. Завершение всего забега выполняется вручную.
- **Отчёты** сохраняют бои, позволяют снять снимок текущего сегмента и экспортировать JSON. Для ручного ввода доступны строки «Имя;Урон;Лечение». Для импорта точных событий в приложении есть шаблон CSV.
- **HUD** открываются независимо и закрываются вместе с ARX. В настройках боевого HUD доступны **Только мой персонаж** и **Я и моя группа**. Пока состав не получен, видна только своя строка. В минимальном режиме видны цветные имена и DPS без фона. Средний режим добавляет HPS, подробный показывает долю, крит, бурст, боевую мощь и доступное HP цели. Прозрачность меняет фон и рамку, а яркость текста сохраняется.

| Клавиша | Действие |
| --- | --- |
| Alt+F8 | Показать или скрыть боевой HUD |
| Ctrl+Alt+F9 | Показать или скрыть HUD мировых боссов |
| Ctrl+Alt+1 / 2 / 3 | Открыть минимальный, средний или подробный режим |
| Ctrl+Alt+PgUp / PgDn | Изменить непрозрачность фона на 5 п. п. |
| Ctrl+Alt+L | Закрепить или разблокировать HUD |
| Alt+R | Завершить текущий сегмент |

В клиенте откройте вкладку **Горячие клавиши**. Она показывает действия и состояние регистрации каждого сочетания. Если сочетание занято, пользуйтесь настройками HUD в ARX. Закрепление доступно, когда Ctrl+Alt+L зарегистрирована и HUD можно разблокировать с клавиатуры.

## Карта, таймеры и прогресс

В **Атласе** выберите зону, затем категорию или введите название на русском либо английском. Встроенный рельеф отрисовывается в 2000 × 1200 с плавными контурами. Колесо масштабирует вокруг указателя, перетаскивание перемещает карту. Двойной щелчок по результату показывает точку крупнее. По щелчку доступны координаты, отметка находки и добавление в маршрут. Маршрут соединяет выбранные точки в порядке добавления. Метки кубов показывают возможные места появления.

В Бертроне, Альтгарде и Нижней Решанте доступны телепорты и другие точки из набора данных. В Поэте, Ишальгене, Средней и Верхней Решанте отмечены места появления существ, дающих души питомцев. Рельеф построен приближённо из координат объектов. Для Внешней Решанты можно загрузить локальный PNG/JPEG через **Снимок зоны…**. Ранее добавленные метки доступны на слое **Архив старых меток** и сохраняют прежнюю привязку. Снимки хранятся отдельно от слоя игровых координат.

Откройте **События → HUD боссов** или нажмите **Ctrl+Alt+F9**. Выберите босса в HUD или нажмите **Следить в HUD** рядом с боссом в списке. Выбор сохраняется в профиле. Чтобы получить время с текущего сервера, откройте в игре **Карта → Исследование → Полевые монстры**. Для полученного времени можно включить звуковое напоминание в **Событиях**. Если отсчёт закончился, HUD ждёт подтверждения от игры. Остальные таймеры используют редактируемое расписание.

Во вкладке **Прогресс** доступны личные ежедневные, еженедельные и постоянные счётчики с ручным сбросом периодов. **Сессия** содержит задачи и ручной журнал кина.

## Данные и обмен

При запуске ARX проверяет ревизию справочника на GitHub и использует локальную копию без сети. Рецепты и цены в калькуляторе не являются актуальной выгрузкой аукциона. Дата среза показана в мастерской.

Общая папка в **Настройках** необязательна. Участники с доступом к одному каталогу могут обмениваться своими метками и таймерами. Для общих меток слоя игровых координат у участников нужна версия 0.2.3 или новее. Снимки карты, отчёты, задачи, кина и личные отметки находок остаются в профиле. Для совместимости с предыдущей бетой ARX продолжает использовать папку %AppData%\ARX Legion Beta.

## Исходный код

Откройте **ARX.Beta.csproj** в IDE с .NET 10 SDK. Для сборки нужны соседние каталоги **src/AionMeter.Core** и **data** из архива исходников. Для установщика нужен Inno Setup 7, а ISCC.exe должен быть в PATH.

~~~powershell
dotnet build .\ARX.Beta.csproj -c Release
.\build-beta.ps1
~~~

Обновление справочника: измените Data/Crafting.json или Data/Reference.json, запустите .\Update-CatalogManifest.ps1 -Revision 2 с номером выше опубликованного и сохраните три JSON-файла одним коммитом.
