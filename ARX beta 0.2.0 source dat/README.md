# ARX 1.0.8 beta

Общедоступное приложение для Aion 2 Global (EU/NA). Для использования ARX не требуется аккаунт или членство в группе.

## Установка

1. Запустите **ARX-Setup-1.0.8-beta.exe**, ознакомьтесь с GPL‑3.0 и завершите установку. Установщик включает .NET и проверяет системные компоненты Windows x64.
2. Если Npcap отсутствует, установщик ARX предложит скачать его с сервера разработчика и открыть официальный мастер. Выберите **Скачать и установить Npcap**, нажмите **Далее** и завершите установку драйвера. Windows может запросить права администратора. Можно пропустить этот шаг и пользоваться Атласом и справочниками. При обычном автообновлении ARX шаг с драйвером пропускается. Для установки Npcap на таком компьютере закройте ARX и запустите установщик вручную. Портативная версия работает из распакованного ZIP с папками **Data** и **GameData**. Для её живой статистики можно установить [Npcap отдельно](https://npcap.com/#download).
3. Запустите ARX. Считывание включится автоматически, а в верхней строке появится статус подключения. Лучше открыть ARX до входа персонажем. Если ARX включён посреди игры, перейдите в другую локацию. При проблемах проверьте адаптер в **Настройках**.
4. Используйте оконный режим без рамки для HUD. Установщик без цифровой подписи.

## Язык интерфейса / Interface language

В **Настройки → Язык / Language** выберите **English**, нажмите **Сохранить язык** и перезапустите ARX. Язык сохранится для клиента, HUD, справочников и будущих обновлений. Сохранённые отчёты и пользовательские записи сохраняют исходный текст.

Open **Settings → Язык / Language**, choose **English**, click **Save language** and restart ARX. To return to Russian, select **Русский** in the same section and restart again.

## Оформление

В **Настройки → Оформление** выберите тему приложения и тему HUD, затем нажмите **Применить темы**. Доступны «Атрея», «Бездна», «Жар», «Иней» и «Графит». Пункт **Как в приложении** связывает тему всех HUD с темой клиента. Настройки сохраняются в профиле и применяются к открытым окнам сразу.

## Обновление приложения

Нажмите **Обновление** рядом со статусом клиента. Кнопка показывает проверку, процент загрузки и готовность установщика. ARX также проверяет новые выпуски на GitHub при запуске и каждые два часа. Установленная версия скачивает файл в фоне и сверяет его размер и SHA‑256. В окне **«Обновление готово. Установить?»** выберите установку сразу, при закрытии или позже. Экран с артом «Врата Атреи» показывает ход установки. После успешного обновления ARX запускается автоматически. Автоматическая проверка настраивается в **Настройки → Обновление ARX**. Переносимая версия предлагает открыть релиз и скачать новый ZIP.

При первом запуске обновлённой версии откроется **Что нового**. Повторно открыть список можно в **Настройки → Обновление ARX → Что нового**.

## Бой, отчёты и забеги

ARX пассивно распознаёт поток Aion 2 через Npcap. Живые показатели и новые записи включают вашего персонажа и полученный состав группы. Пока состав неизвестен, отображается только ваш персонаж после распознавания. Прочерк означает, что боевых данных пока нет. Состав обновляется при получении нового списка или сообщения о выходе из группы. На массовых боях сервер может присылать часть урона. Имена и боевая мощь показываются по данным сервера. Трафик игры, сырые пакеты и отчёты не отправляются из приложения. NCSOFT не предоставляла ARX отдельное разрешение на захват.

- **Монитор** показывает ваш DPS отдельно от общего, индивидуальные строки участников и график. Метка **ВЫ** ставится по идентификатору собственного персонажа из пакета игры. Если ARX запущен после входа и ещё не получил этот пакет, смените локацию или укажите точное имя в разделе **Настройки → Подключение Aion 2**. Резервный поиск требует единственного совпадения. В боевых отчётах доступны навыки, HPS, крит, атаки со спины, максимальный и полученный урон. Поглощение щитами и вклад баффов не рассчитываются.
- **Забеги** автоматически записывают Пещеру Крао, Драупнир, Каньон Уругугу, Небесный остров Вакрона, Храм Огня и Логово Свирепого Рога. Запись начинается после первого полученного боевого сегмента распознанного персонажа. Переход внутри той же карты сохраняет забег. Победа над известным финальным боссом завершает забег, а смена карты до подтверждения сохраняет его как прерванный. Для остальных активностей доступны ручное начало и завершение. Можно сравнить средний DPS двух забегов и экспортировать JSON.
- **Разбор по боссам** открывается из соответствующей попытки в забеге. Потяните мышью по графику, чтобы увидеть вклад участников на выбранном отрезке, или нажмите **Пик за 5 секунд**. Выбор использует посекундные данные. Полный отчёт сохраняет общий урон и разбивку навыков, а при неполных данных график об этом сообщает. В старых забегах детальный отчёт доступен, если бой ещё есть в истории.
- **Отчёты** сохраняют бои, позволяют снять снимок текущего сегмента и экспортировать JSON. Для ручного ввода доступны строки «Имя;Урон;Лечение». Для импорта точных событий в приложении есть шаблон CSV.
- **HUD** открываются независимо и закрываются вместе с ARX. В настройках боевого HUD доступны **Только мой персонаж** и **Я и моя группа**. Пока состав не получен, видна только своя строка. Подробный режим выбран по умолчанию. Во всех режимах показаны DPS и общий урон (DMG), а лечение остаётся в отчётах. В минимальном режиме фон прозрачен и доступна кнопка **↕**. Прозрачность меняет фон и рамку, а яркость текста сохраняется.

| Клавиша | Действие |
| --- | --- |
| Alt+F8 | Показать или скрыть боевой HUD |
| Ctrl+Alt+F9 | Показать или скрыть HUD мировых боссов |
| Ctrl+Alt+F10 | Показать или скрыть миникарту |
| Ctrl+Alt+F11 | Закрепить миникарту с пропуском щелчков или разблокировать |
| Ctrl+Alt+1 / 2 / 3 | Открыть минимальный, средний или подробный режим |
| Ctrl+Alt+PgUp / PgDn | Изменить непрозрачность фона на 5 п. п. |
| Ctrl+Alt+L | Закрепить или разблокировать HUD |
| Удерживать Alt | Временно включить мышь для закреплённого боевого HUD или миникарты |
| Alt+R | Завершить текущий сегмент |

В клиенте откройте вкладку **Горячие клавиши**. Она показывает действия и состояние регистрации каждого сочетания. Если сочетание занято, пользуйтесь настройками HUD в ARX. Закрепление доступно, когда Ctrl+Alt+L зарегистрирована и HUD можно разблокировать с клавиатуры.

Пока удерживаете **Alt**, можно нажимать кнопки HUD и перетаскивать окно за заголовок. После отпускания Alt закреплённое окно снова пропускает щелчки.

## Карта, таймеры и прогресс

В **Атласе** выберите зону, затем категорию или введите название на русском либо английском. Встроенный рельеф построен по более плотной сетке высот. При приближении ARX перерисовывает видимый участок под разрешение экрана. Колесо масштабирует вокруг указателя, перетаскивание перемещает карту. Двойной щелчок по результату показывает точку крупнее. По щелчку доступны координаты, отметка находки и добавление в маршрут. Маршрут соединяет выбранные точки в порядке добавления. Метки кубов показывают возможные места появления.

**Миникарта HUD** открывает отдельное окно поверх игры в оконном режиме без рамки. Кнопка в Атласе передаёт текущую зону, слой и выделенную метку. На миникарте доступны поиск на русском и английском в выбранной зоне, категории и фильтр «Только мои метки». Выберите результат или нажмите Enter, чтобы приблизить точку. Кнопка **Найдено** обновляет ту же метку в Атласе, а **В Атлас** открывает её на большой карте. Положение окна и выбранная точка сохраняются при закрытии. Зону можно выбрать вручную.

В Бертроне, Альтгарде и Нижней Решанте доступны телепорты и другие точки из набора данных. В Поэте, Ишальгене, Средней и Верхней Решанте отмечены места появления существ, дающих души питомцев. Рельеф построен приближённо из координат объектов. Для Внешней Решанты можно загрузить локальный PNG/JPEG через **Снимок зоны…**. Ранее добавленные метки доступны на слое **Архив старых меток** и сохраняют прежнюю привязку. Снимки хранятся отдельно от слоя игровых координат.

Откройте **События → HUD боссов** или нажмите **Ctrl+Alt+F9**. Выберите босса в HUD или нажмите **Следить в HUD** рядом с боссом в списке. Выбор сохраняется в профиле. Чтобы получить время с текущего сервера, откройте в игре **Карта → Исследование → Полевые монстры**. Для полученного времени можно включить звуковое напоминание в **Событиях**. Если отсчёт закончился, HUD ждёт подтверждения от игры. Остальные таймеры используют редактируемое расписание.

Во вкладке **Прогресс** доступны личные ежедневные, еженедельные и постоянные счётчики с ручным сбросом периодов. Для автозачёта включите запись экспедиций в **Забегах**. В **Прогрессе** нажмите **Текущий персонаж**, выберите экспедицию в поле **Отслеживание** и добавьте цель. Подтверждённая победа добавит одно прохождение на сервере этого персонажа. **Сессия** содержит задачи и ручной журнал кина.

## Билды, гайды и питомцы

- **Билды и гайды → Мой билд**. Укажите имя и при необходимости сервер, выберите класс и тип боя. Сохраните выбор, чтобы переключаться между персонажами через список. Для каждого из восьми классов есть PvE-варианты для группы и соло. Карточки показывают порядок характеристик, умения, четыре стигмы, первые действия в бою и приоритеты экипировки. Имя распознанного персонажа может подставляться при добавлении. Выбор хранится в локальном профиле ARX и не меняет настройки в игре.
- **Билды и гайды → Гайды по боям**. Выберите активность или найдите босса по русскому или английскому имени. Памятки содержат подготовку, сигналы механик, действия по ролям и разбор частых ошибок. Описаны экспедиции, Кошмары, Возвышение, Преодоление и рейд Лудры.
- **Питомцы**. Поиск по имени и известному региону, фильтр по семейству, бонусы за владение и подсказки по душам. Во вкладке **Как прокачивать** собраны шаги по коллекции, доскам семейств и превращению. Каталог и памятки доступны без сети.

## Данные и обмен

При запуске ARX проверяет ревизию справочника на GitHub и использует локальную копию без сети. Рецепты и цены в калькуляторе не являются актуальной выгрузкой аукциона. Дата среза показана в мастерской.

Общая папка в **Настройках** необязательна. Участники с доступом к одному каталогу могут обмениваться своими метками и таймерами. Для общих меток слоя игровых координат у участников нужна версия 0.2.3 или новее. Снимки карты, отчёты, задачи, кина и личные отметки находок остаются в профиле. Для совместимости с предыдущей бетой ARX продолжает использовать папку %AppData%\ARX Legion Beta.

## Исходный код

Откройте **ARX.Beta.csproj** в IDE с .NET 10 SDK. Для сборки нужны соседние каталоги **src/AionMeter.Core** и **data** из архива исходников. Для установщика нужен Inno Setup 7, а ISCC.exe должен быть в PATH.

~~~powershell
dotnet build .\ARX.Beta.csproj -c Release
.\build-beta.ps1
~~~

Обновление справочника: измените Data/Crafting.json или Data/Reference.json, запустите .\Update-CatalogManifest.ps1 -Revision 2 с номером выше опубликованного и сохраните три JSON-файла одним коммитом.

Для подписи приложения и установщика запустите `build-beta.ps1 -SigningThumbprint <отпечаток>`. Нужен сертификат подписи кода с доступным ключом в хранилище текущего пользователя и SignTool из Windows SDK. Сборка проверяет подписи и метки времени перед публикацией.
